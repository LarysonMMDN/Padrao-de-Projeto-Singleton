# Projeto Java — Padrão Singleton

Projeto desenvolvido em Java com interface gráfica para apresentação acadêmica na Faculdade FATESG.

O principal objetivo foi aplicar na prática o padrão de projeto **Singleton**, garantindo que uma determinada classe possua apenas uma única instância durante a execução da aplicação.

O projeto busca demonstrar o funcionamento do padrão e sua utilização no controle de instâncias.

### Tecnologias utilizadas
- Java
- Interface gráfica
- Programação Orientada a Objetos (POO)
- Design Pattern Singleton

**Finalidade:** atividade acadêmica com foco na aplicação prática do padrão Singleton.
